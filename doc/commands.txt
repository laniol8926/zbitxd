These are text commands that can be entered from the keyboard
\callsign [callsign]
	Sets your callsign to the following string.
\grid [grid]
	Sets your grid (six letters) that is used in FT8 and other modes to
	indicate your approximate locationi.
\freq [frequency in Hz or Kilohertz]
	You can also type just 'f' instead 'freq'
	if you the type '\f 7050' it will set be the same as '\freq 7050000'
	Refused while transmitting.
\cwdelay [100-2000] msec. How long radio remains in transmit in CW before
	timing out to rx. ex: "\cwdelay 500"
\cwinput [IAMBIC/IAMBICB/STRAIGHT]
	Chooses the CW input method between straight key(STRAIGHT) and
	Iambic keyer, mode A or B (IAMBIC/IAMBICB).
\mode [USB/FT8/FT4]
	Chooses from the modes available in the mode selection control.
	You can use 'm' instead of 'mode'
\t
	Puts the radio into transmit. You can also use Ctrl-T
\r
	Puts the radio into receive. You can also use Ctrl-R
\txpitch [in Hz]
	Sets the tone of transmit tone of the CW.
	Ex: \txpitch 700
	Refused while transmitting.

abort
	Immediately stop TX and, if Auto CQ is running, stop it too. Also
	clears the logger's CALL field, so a fresh CQ reply auto-answers
	correctly next time (an abandoned/aborted manual attempt used to
	leave CALL stuck, permanently blocking auto-answer until something
	else overwrote it).

FT8_AUTO OFF/ON/AUTOCQ
	AUTOCQ transmits CQ on repeat and auto-answers whoever replies,
	cycling back to CQ once each QSO closes out. Arm/disarm it by
	clicking TX Enabled while idle (see AUTOCQSTART below), not by
	setting this field directly.
FT8_TX1ST ON/OFF
FT8_REPEAT 1-10
	How many times to repeat a CQ/reply before giving up. See
	FT8_REPEAT_RESET below to reset the on-screen countdown mid-cycle
	without waiting for it to run out on its own.


Added by the generic-rig-backend fork
-------------------------------------
These aren't in upstream zbitxd.

RIGMODEL [hamlib model id]
RIGDEVICE [serial device path]
RIGBAUD [baud rate]
	CAT connection for the generic rig backend (radio=generic). Set
	through the Connect panel's pickers, not normally typed by hand.
CAPTUREDEV [ALSA device]
PLAYBACKDEV [ALSA device]
	Audio devices for the generic rig backend. Also normally set
	through the Connect panel.
AUTOCQSTART
	Arms Auto CQ (see FT8_AUTO above) -- equivalent to clicking TX
	Enabled while idle with FT8_AUTO set to AUTOCQ.
FT8_REPEAT_RESET
	Resets the on-screen FT8 repeat countdown back to FT8_REPEAT's
	value on demand, without waiting for it to run out.
TXPOWER [text]
ANTENNA [text]
COMMENTS [text]
	Logged with every QSO. TXPOWER gets its own logbook column;
	ANTENNA and COMMENTS are folded into the logged Comments field
	alongside any generic-rig description.
UDPLOGHOST [host]
UDPLOGPORT [port]
	Live-broadcasts each logged QSO to a UDP-listening logger (e.g.
	CQRLog) using WSJT-X's own UDP "QSO Logged" protocol. UDPLOGHOST
	blank disables it (the default). See README.md's Logging section.
LOGEXPORT
	Exports the whole logbook to a correctly-formatted ADIF 3.1.4
	file; the client then downloads /logbook_export.adi. Bound to the
	"Export ADIF" button in the FT8 panel's toolbar.
QSODEL [logbook id]
	Deletes a single logbook row by id.
